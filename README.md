# template_fastapi
Template of python FASTAPI dockerised server

# Déploiement

Une fois déployé avec make up, le serveur est accessible via localhost:8000, le swagger est accessiblevia localhot:8000/api/docs

Prometheus est accessible via localhost:9090
Grafana est accessible via localhost:13000.

Pour importer le dashboard template: aller dans grafana, dashboards, new, dashboard, import, soit importer le fichier soit copier coller son contenu
